# Realistic Ocean Waves Mod

Enhance your Minecraft world with realistic ocean waves and boat interactions.

## Features

- Realistic ocean waves with physics
- Boat interaction with waves
- Multiplayer support for synchronized wave data

## Requirements

- Minecraft Java 1.20.4
- Fabric Loader 0.15.3 or higher
- Fabric API 0.92.0 or higher

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/realistic-ocean-waves-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

Once installed, the mod will automatically enhance your ocean environments with realistic waves and boat interactions. No additional configuration is required.

## Configuration

The mod does not require any configuration files. All settings are handled internally.
